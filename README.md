# 🌱 AgroQuiz Sustentável

## Descrição

O AgroQuiz Sustentável é um projeto educativo desenvolvido para o Concurso Agrinho 2026. O objetivo é promover a conscientização sobre práticas sustentáveis no campo por meio de um quiz interativo, onde os usuários testam seus conhecimentos sobre preservação ambiental, uso consciente dos recursos naturais e tecnologias sustentáveis aplicadas à agricultura.

A cada pergunta respondida corretamente, o participante acumula pontos e recebe uma avaliação final de seu conhecimento sobre sustentabilidade rural.

---

## Objetivo do Projeto

Desenvolver uma ferramenta educativa e interativa que incentive estudantes e a comunidade a refletirem sobre a importância da sustentabilidade no meio rural, contribuindo para a formação de cidadãos mais conscientes e comprometidos com o meio ambiente.

## Como Executar

### Executar Localmente

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em qualquer navegador.
4. Responda às perguntas e confira sua pontuação.

### Executar Online

Acesse a versão publicada através do GitHub Pages.

## Relação com o Tema Agrinho 2026

### Tema:

**Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.**

O AgroQuiz Sustentável está alinhado ao tema do Agrinho 2026 ao abordar questões relacionadas à preservação ambiental, uso consciente dos recursos naturais e adoção de práticas sustentáveis no campo. O projeto busca demonstrar que o conhecimento é uma ferramenta essencial para promover o desenvolvimento rural sustentável e garantir um futuro equilibrado para as próximas gerações.
